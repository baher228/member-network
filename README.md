# Member Network

Know your members: opt-in questionnaire → member graph → hybrid recommender (collaborative filtering + content embeddings) → one explained intro per member per week (written by Grok) → speaker finder with public evidence (GitHub, Devpost, Hacker News, Luma).

Built at the London Grok Bot "Community Engineering" hackathon (Track 2 · Know Your Members). MIT licensed. Full README lands with the MVP PR.
